## Source precedence
Original signed commercial/project documents prevail legally. Later user-directed additions require written client scope alignment, especially MCP, entitlements and new admin management. Earlier project/database architecture drafts retain technical value but their explicit original subscription/MCP exclusions have been superseded in internal planning.

## Starting point
Read `DEVELOPMENT_RULES.md`, `PROJECT_MEMORY.md`, and `SYSTEM_ARCHITECTURE.md`; then execute a strictly scoped **Step 1** setup prompt. No features or finalized database models should be implemented before review.
